# L.AI / LoreAI — прототип

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере на компьютере или телефоне.
3. На Android можно открыть в браузере. Чтобы установить как полноценное приложение, позже понадобится PWA-манифест/service worker или упаковка в Android-приложение.

## Что уже работает в этом прототипе
- Тёмная и светлая темы.
- Создание карточек персонажей: имя, фандом, пол/местоимения, внешность, характер, биография.
- Отдельные чаты и независимые сюжетные ветки.
- Выбор роли пользователя в чате.
- Настройки стиля общения, мрачности сюжета и мата (пока сохраняются как настройки интерфейса).
- Простейшая демонстрация исправления нескольких распространённых опечаток.
- Локальное сохранение чатов и персонажей в браузере, без аккаунта.

## Что пока НЕ реализовано
- Настоящая генерация ответов нейросетью: ответы демонстрационные.
- Автоматическая долговременная память с семантическим поиском по истории.
- Надёжная работа с группами персонажей и фандомным лором.
- Полноценная коррекция любых опечаток.
- Гарантия бесплатной работы при большом числе пользователей.
- Защищённая синхронизация между устройствами и резервные копии.

Для настоящего ИИ потребуется выбрать модель и подключить её безопасно через сервер или локальную модель. Не помещайте секретные API-ключи в HTML/JavaScript приложения.


## Обновление прототипа
- Добавлен обучающий туториал при первом запуске, с возможностью пропуска и повторного открытия в настройках.
- Добавлена шпаргалка по синтаксису: `*действие*`, `"мысль"`, `((подсказка ИИ))` и диалог нескольких персонажей.
- В параметрах чата добавлены концептуальные лимиты: до 3 игроков и до 15 ИИ-персонажей.
- Важно: настоящий онлайн-мультиплеер, синхронизация между устройствами и ответы реальной языковой модели пока не реализованы. Лимиты показывают целевую спецификацию, а не работающую сетевую функцию.


## Обновление: локальная память и установка
- Чаты и персонажи сохраняются в локальном хранилище браузера на этом устройстве; аккаунт не нужен. Очистка данных браузера может удалить их.
- Добавлены экспорт и импорт резервной копии в JSON. Храни копию в безопасном месте и не делись ею, если в чатах есть личная информация.
- Добавлены PWA manifest, SVG-иконка и service worker для кеширования оболочки и запуска без сети после первой загрузки.
- Для установки PWA сайт должен быть размещён по HTTPS (или работать на localhost). Открытие одного HTML-файла напрямую не устанавливает полноценную PWA.
- Размер интерфейса очень маленький; языковая модель в архив не включена. Настоящий ИИ пока не подключён. Локальный ИИ будет зависеть от модели, мощности телефона и дополнительного места для скачивания модели. Нулевые расходы на облако возможны только если генерация выполняется на устройстве или используется внешний бесплатный сервис с его ограничениями.
- В этом прототипе нет настоящего мультиплеера, защищённой синхронизации или отдельной серверной памяти.


## Бесплатная локальная нейросеть (экспериментальная интеграция)
- В настройках появилась загрузка модели `onnx-community/Qwen2.5-0.5B-Instruct` через Transformers.js.
- Генерация задумана локально в браузере, без платного API и без отправки чата на сервер модели.
- Для первой загрузки нужны интернет и свободное место: веса модели могут занимать сотни мегабайт. Они не включены в ZIP, поэтому сам архив остаётся маленьким.
- Требуется современный браузер; WebGPU ускоряет работу, а WASM может быть медленнее. Совместимость и производительность на конкретном Android-телефоне не гарантируются.
- Чтобы модуль и кеш моделей работали надёжнее, открой проект через HTTPS (например, как размещённый сайт/PWA), а не через `file://`.
- Это экспериментальный прототип: модель 0.5B сравнительно небольшая и может ошибаться, особенно в длинном ролеплее. Память чатов хранится локально в браузере, но веса модели кешируются отдельно и браузер может очистить их.


## Fix v3: external model downloads
The service worker now caches only same-origin LoreAI files. It no longer catches failed requests to Hugging Face or the JavaScript CDN and substitutes index.html, which can cause errors like `Unexpected token '<' ... is not valid JSON`. The cache version was also bumped so browsers replace the old service worker.
